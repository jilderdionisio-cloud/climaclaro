# ClimaClaro

Aplicación web ligera para consultar el clima actual de una ciudad o de la ubicación del visitante.

## Tecnologías

- HTML, CSS y JavaScript sin frameworks.
- [Open-Meteo](https://open-meteo.com/) para geocodificación y datos meteorológicos en tiempo real.

## Uso local

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. Es necesaria conexión a internet para consultar la API de Open-Meteo.

## Funciones

- Búsqueda de ciudades.
- Consulta opcional mediante geolocalización del navegador.
- Temperatura, humedad y viento actuales con sus unidades.
- Pronóstico de tres días con temperaturas máxima/mínima y probabilidad de precipitación.

## Uso de Open-Meteo

La app usa la capa pública de Open-Meteo para fines no comerciales y académicos, sin clave de API. Mantiene la atribución visible a Open-Meteo y debe respetar los límites publicados por el proveedor.
