# ClimaClaro

Aplicación web ligera para consultar el clima actual de una ciudad o de la ubicación del visitante.

## Tecnologías

- HTML, CSS y JavaScript sin frameworks.
- [Open-Meteo](https://open-meteo.com/) para geocodificación y datos meteorológicos.

## Uso local

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático. Es necesaria conexión a internet para consultar la API de Open-Meteo.

## Funciones

- Búsqueda de ciudades.
- Consulta opcional mediante geolocalización del navegador.
- Temperatura, sensación térmica, humedad, viento y precipitación.
